# Branding assets for documents

Drop these files here (PNG, transparent background). The PDF templates pick
them up automatically; without them the letterhead is text-only.

| File | Used on | Suggested size |
| --- | --- | --- |
| `logo.png` | Letter letterhead | ~400 x 400 px |
| `signature.png` | Signature block on all documents | ~600 x 200 px |

The signatory's name and title come from `ISSUER_SIGNATORY_NAME` /
`ISSUER_SIGNATORY_TITLE` in `.env`.
