# HTML basics

HTML describes the **structure** of a page.

```html
<h1>Hello Beyownd</h1>
<p>My first page.</p>
<a href="https://beyownd.in">Visit Beyownd</a>
```

- `<h1>` is the main heading — use one per page.
- `<p>` is a paragraph.
- `<a>` is a link.

**Practice:** make a page with your name as the heading and two paragraphs about yourself.
