When you open a website, your browser sends an **HTTP request** to a server.
The server sends back an **HTTP response** — usually HTML, CSS and JavaScript.

```text
Browser ──request──►  Server
Browser ◄─response──  Server
```

## Key words

- **Client** — the browser on your phone or laptop.
- **Server** — a computer that answers requests.
- **URL** — the address you type, e.g. `https://beyownd.in`.

> Try it: open any website, press `F12`, go to the **Network** tab and reload.
> Every line you see is one request.
